# KujataEngine2 点群のデモ

## やったこと
* 点を立方体の形にして、球を当てるとお互い崩れる。
* 100万個以上の点をコンピュートシェーダーで動かす。
* ホットリロードでImguiの調整項目がセーブ・ロードされる。

## かっこいいところ、見どころ

* 点が細かいので塵みたいに見える。
* 立方体だけではなく背景にも天球に点を使用して、星のように演出。

## こだわり

* 使われているのはすべて板ポリ。
* 各板ポリを動かし続けながら形を保たせる。
* 点の位置をCPUへ読み戻さず、GPUの中だけで更新して描く。
* 板ポリをインスタンシングで描く。

## 操作

* 歩く : WASD
* 見回す : 右クリックホールド
* 球を撃つ : 左クリックorスペースキーでカーソルの方向に発射（長押し可）
